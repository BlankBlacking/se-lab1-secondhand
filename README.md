## 实验二：软件设计与建模

见 [`lab2/README.md`](lab2/README.md)。

11 张 UML 图（结构 5 / 行为 4 / 交互 2）覆盖任务书"三类各至少一种、类图必画"的要求；
13 屏界面按"用户端 H5（390×844）+ 管理端桌面 Web（1440×900）"划分。

三条设计主线：

1. **状态机集中化**：商品 7 态、预约 7 态的合法转换由转移表实现，非法转换拒绝且不改状态（REQ-005、REQ-030）。
2. **有效预约唯一靠数据库兜底**：`reservation.active_flag` 生成列 + `UNIQUE(goods_id, active_flag)`，
   配合应用层 `SELECT ... FOR UPDATE`（REQ-012、REQ-020）。
3. **事务与日志分离**：预约与商品状态同事务提交，操作日志走独立事务，失败也留痕（REQ-017、REQ-020）。
